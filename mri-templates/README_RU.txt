МРТ ГОЛОВЫ • версия 1.0

Состав комплекта
MRI_Head_Universal.docx — полный конструктор: инструкция, базовый протокол, 12 специальных модулей и блок отдельной находки F01.
MRI_Head_Universal.dotx — тот же конструктор как шаблон Word без макросов.
MRI_Head_Base.docx / .dotx — компактный базовый протокол для повседневной работы.
MRI_Head_Modules.docx — библиотека дополнительных блоков для копирования в базовый протокол.
MRI_Head_Blocks.json — редактируемый реестр для дальнейшего расширения.

Заполнение
Все поля жёлтые и заключены в ⟦двойные скобки⟧. В Word это текстовые элементы управления содержимым. В редакторах с ограниченной поддержкой элементов управления можно заменить выделенный текст обычным вводом.
Сохраните рабочую копию; заполните общие данные, оставьте выполненные серии и только нужные анатомические блоки. Поле с несколькими вариантами — подсказка для выбора одного варианта, а не готовое описание.
Размеры указаны в мм, кроме явно обозначенных единиц. Стороны пишутся словами «справа» и «слева».
В итоговом протоколе должен остаться один раздел «Заключение». Подсказки, строку источников, служебную инструкцию и неиспользуемые разделы удаляют перед выдачей. Подсветку при необходимости снимают в настройках форматирования текста.

Расширение
Для новой области сохраните общие данные, методику, заключение и подпись; замените анатомический базовый блок. Для нового описательного блока добавьте модуль с уникальным ID, областью применения, методикой, описанием и выводом. В JSON поля помечаются [[подсказка]]. Новые модули не требуют изменения уже существующих.

Изменения по отношению к исходникам
Учтены все 15 приложенных .dot-файлов. Взаимоисключающие варианты, заполненные находки, старые даты и Ф.И.О. врача заменены полями. Торговая марка и доза контраста не установлены по умолчанию. Исторические критерии McDonald / MAGNIMS и готовые диагнозы из исходников не перенесены как автоматические выводы; при формальной оценке указываются используемая редакция и обоснование. MTA и Fazekas заполняются при применении шкал, без автоматического диагноза. Специальные последовательности отмечаются по факту выполнения.
