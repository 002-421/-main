# Шаблоны МРТ головы

Все поля для заполнения выделены жёлтым. Состав подготовлен из 15 предоставленных исходных шаблонов.

- [Полный шаблон Word](MRI_Head_Universal.docx) и [PDF для просмотра](MRI_Head_Universal.pdf).
- [Базовый бланк Word на 2 страницы](MRI_Head_Base.docx) и [PDF](MRI_Head_Base.pdf).
- [Библиотека дополнительных блоков Word](MRI_Head_Modules.docx).
- [Весь комплект ZIP](MRI_Head_Template_Kit.zip), включая DOTX и реестр блоков JSON.

Для сохранения файла на компьютер откройте его страницу в GitHub и нажмите **Download raw file / Скачать исходный файл**.
