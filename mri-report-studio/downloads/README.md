# Готовые файлы МРТ Студии

- [Небольшой установочный комплект Windows, около 205 КБ](MRI_Report_Studio_Windows_Setup.zip). Распакуйте весь архив и запустите `Install.cmd`. Он загрузит официальный Electron с GitHub (около 150 МБ), проверит SHA256 и создаст папку приложения на рабочем столе. Интернет нужен только для установки. Права администратора не требуются; политика выполнения и настройки защиты не меняются.
- [Автономная браузерная версия, около 173 КБ](MRI_Report_Studio_Browser.zip). Распакуйте и откройте `index.html` в Chrome или Edge. Для PDF выберите «Сохранить как PDF» в окне печати.
- [Самостоятельный HTML-файл](MRI_Report_Studio.html).
- [Изображение интерфейса](MRI_Report_Studio_Preview.png).

На странице ZIP-файла в GitHub используйте **Download raw file / Скачать исходный файл**. Скачивайте весь архив и распаковывайте целиком.

Приложение проверено в облачной среде: заполнение, форматирование, модули, черновики, копирование и настоящий PDF. Запуск на Windows пока не проверялся. У приложения нет собственной цифровой подписи издателя.
