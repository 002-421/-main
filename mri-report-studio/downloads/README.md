В версии 0.3.0 всё описание редактируется в одном поле, без правой панели. Слева выбираются **зона → шаблон**, а также дополнительные описания с поиском и предварительным просмотром. Жёлтые подсказки заменяются текстом при начале ввода. Можно сохранять собственные дополнительные блоки, изменять шаблоны и выбирать врача для подписи.

Русская орфография и базовая грамматика проверяются прямо в документе: красное и синее подчёркивание, варианты исправления и личный словарь. Кнопка **Подсветить неизменённое** подсвечивает части, оставшиеся без изменений относительно шаблона. Проверка работает локально, без отправки описаний в интернет.

Описание сохраняется кнопкой **Сохранить Word** или **PDF**. Оформление основано на ранее подготовленных Word-шаблонах. Повторно открываются DOCX, выгруженные из приложения и не изменённые другим редактором; старые JSON-черновики также читаются.

При обновлении закройте старое приложение и запускайте версию из новой папки `App_…`. Функции проверяются в облачной среде на Linux; непосредственный запуск Windows EXE здесь не проверяется. У приложения нет собственной цифровой подписи издателя.

Официальный логотип МРТ Альянс включён в приложение и его значок Windows. В «Врач и настройки» можно изменить Ф.И.О. врача или загрузить другой логотип PNG/JPEG/WebP. Логотип интерфейса не меняет оформление исходного шаблона Word.
