# Скачать МРТ Альянс 0.2.0

Нажмите одну из прямых ссылок ниже обычной левой кнопкой мыши. ZIP скачается целиком; искать команду скачивания в контекстном меню папки GitHub не нужно.

- **[Скачать приложение для Windows](https://github.com/002-421/-main/raw/refs/heads/codex/mri-report-studio/mri-report-studio/downloads/MRI_Alliance_Windows_Setup.zip)**. Распакуйте весь архив и запустите `Install.cmd`. Он загрузит официальный Electron с GitHub (около 150 МБ), проверит SHA256 и создаст папку приложения на рабочем столе. Интернет нужен только для установки. Права администратора не требуются; ExecutionPolicy и настройки защиты не меняются.
- **[Скачать автономную браузерную версию](https://github.com/002-421/-main/raw/refs/heads/codex/mri-report-studio/mri-report-studio/downloads/MRI_Alliance_Browser.zip)**. Распакуйте и откройте `index.html` в Chrome или Edge. Для PDF выберите «Сохранить как PDF» в окне печати.
- [Открыть самостоятельный HTML-файл](https://github.com/002-421/-main/raw/refs/heads/codex/mri-report-studio/mri-report-studio/downloads/MRI_Alliance.html). Если браузер показывает текст, сохраните его как `MRI_Alliance.html` или используйте ZIP выше.
- [Посмотреть интерфейс](MRI_Alliance_Preview.png).
- [Лицензии компонентов](THIRD_PARTY_LICENSES.txt).

В этой версии убраны возраст и клиническая цель, добавлены редактирование основных разделов шаблона, сохранение в DOCX и локальная проверка русского текста. Грамматическая проверка использует правила распространённых ошибок и не заменяет проверку врачом.

После обновления запускайте приложение из новой папки `App_…`. Кнопка **Шаблон → Сохранить шаблон** сохраняет настройки для новых описаний. Кнопка **DOCX** сохраняет документ Word. Повторно открываются файлы DOCX, выгруженные из приложения и не изменённые другим редактором; старые черновики JSON также поддерживаются.

Приложение проверяется в облачной среде на Linux. Запуск на Windows пока не проверялся. У приложения нет собственной цифровой подписи издателя.
