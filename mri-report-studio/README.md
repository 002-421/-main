# МРТ · Студия описаний

Локальное приложение для составления протоколов МРТ из модулей. Исходная библиотека подготовлена из 15 предоставленных шаблонов. Приложение не генерирует диагнозы: врач заполняет поля, редактирует описание и проверяет заключение.

## Запуск из исходников

Требуется Node.js 24 LTS. Зависимости фиксированы в `package-lock.json`.

```bash
npm ci
npm run build
npm run desktop:install
npm start
```

Разработка в браузере: `npm run dev`. Готовый `dist/index.html` самодостаточен: стили, код и библиотека встроены. Его можно открыть в Chrome/Edge без сервера. В браузерной версии PDF сохраняется через окно печати; в Electron — напрямую через выбор файла.

В этой облачной среде домашняя папка недоступна для записи. Для установки Electron используются поддерживаемые параметры кеша и прокси Node:

```bash
npm_config_cache=/workspace/.cache/npm npm ci
NODE_USE_ENV_PROXY=1 electron_config_cache=/workspace/.cache/electron npm run desktop:install
```

## Проверки

```bash
npm test
npm run test:browser
```

Модель проверяется штатным runner Node. Функциональный сценарий запускает настоящий Electron и собранную браузерную версию: заполнение полей, ручное форматирование, добавление и восстановление модулей, создание своих блоков, сохранение/загрузка, копирование и настоящий экспорт PDF. В Linux без дисплея тест использует headless Ozone; нужен Chromium для отдельной браузерной проверки (`CHROMIUM_PATH`). Путь кеша в тесте относится к данной облачной среде.

## Сборка Windows

```bash
npm run build
python3 scripts/package_windows.py
```

Скрипт получает официальный Windows x64 дистрибутив Electron, сверяет SHA256 с опубликованным `SHASUMS256.txt`, добавляет приложение и лицензии. Результат — переносимая папка с EXE в ZIP, без установщика и подписи издателя. Нужны Python 3.10+ и доступ к GitHub releases. Сборка на Linux не означает проверку запуска на Windows.

## Устройство

- `src/templates.json` — исходные базовые разделы и модули.
- `src/model.ts` — конструктор документов, модулей и проверка форматов файлов.
- `src/editor.ts` — Tiptap, изолированные разделы и редактируемые поля.
- `src/main.ts` — интерфейс, локальное сохранение и библиотека.
- `electron/` — минимальная оболочка, файловый диалог PDF и буфер обмена.

Текст, форматирование и заполненные поля сохраняются в `.mri.json`. Один текущий черновик и собственная библиотека хранятся локально. Отключённые модули сохраняются в памяти в пределах текущей сессии. Долговременное хранение нескольких исследований обеспечивают отдельные файлы описаний.

В Electron отключён Node.js в редакторе, включены sandbox/context isolation, внешние HTTP-запросы и новые окна блокируются. Внешние данные проходят проверку структуры до замены текущего документа. Стандартный медицинский контент не содержит предустановленных находок или фиксированной дозы контраста.

Реализовано базовое форматирование в стиле текстового редактора. Полная совместимость с файлами DOCX, колонтитулы Word, отслеживание правок, интеграция с МИС и автоматическая диагностика в эту версию не входят. В Word описание можно перенести кнопкой «Копировать».
