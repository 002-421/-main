# МРТ Альянс

Локальное приложение для составления протоколов МРТ из модулей. Исходная библиотека подготовлена из 15 предоставленных шаблонов. Врач заполняет поля, редактирует описание и проверяет заключение.

## Готовое приложение

[Скачать комплект для Windows](https://github.com/002-421/-main/raw/refs/heads/codex/mri-report-studio/mri-report-studio/downloads/MRI_Alliance_Windows_Setup.zip). Распакуйте архив целиком и запустите `Install.cmd`. Он загрузит официальный Electron с GitHub, проверит SHA256 и создаст новую папку приложения на рабочем столе. Интернет нужен для установки; работа с описаниями и проверка русского текста выполняются локально.

[Скачать браузерную версию](https://github.com/002-421/-main/raw/refs/heads/codex/mri-report-studio/mri-report-studio/downloads/MRI_Alliance_Browser.zip). Распакуйте и откройте `index.html` в Chrome или Edge.

## Версия 0.2.0

- В основных данных нет возраста и клинической цели. Дата рождения сохранена.
- **Шаблон** открывает редактирование основных разделов: текст и подсказки полей, добавление, удаление, переименование и порядок разделов. Изменения сохраняются отдельно для каждой области и применяются к новым описаниям. Текущий рабочий текст при выходе из режима восстанавливается.
- **DOCX** сохраняет настоящий документ Word с текстом, форматированием, списками и таблицами. В режиме редактирования шаблона эта кнопка сохраняет шаблон DOCX. **Открыть** восстанавливает DOCX, выгруженный из приложения, включая поля и собственные модули; старые файлы `.mri.json` также читаются.
- Проверка русского текста работает без отправки описания в интернет: словарь орфографии, медицинские термины, собственные слова и правила распространённых грамматических и пунктуационных ошибок. Подсказки требуют проверки врачом; это базовая грамматическая проверка, без полного анализа всех конструкций русского языка.

Выгруженный DOCX можно редактировать в Word. Обратное открытие DOCX в приложении поддерживается, пока файл не был изменён другим редактором: вложенные данные проверяются на соответствие видимому тексту. Импорт произвольных файлов Word и изменений, сделанных в Word, не реализован. Для таких файлов используйте копирование текста в редактор.

Один рабочий черновик, библиотека, настройки шаблонов и пользовательские слова хранятся локально. Для хранения нескольких исследований сохраняйте каждое отдельным DOCX или PDF. JSON остаётся только форматом переноса библиотеки модулей и совместимости со старыми черновиками.

## Запуск из исходников

Требуется Node.js 24 LTS. Зависимости фиксированы в `package-lock.json`.

```bash
npm ci
npm run build
npm run desktop:install
npm start
```

Разработка в браузере: `npm run dev`. Готовый `dist/index.html` самодостаточен: стили, код, библиотека шаблонов и словарь встроены. Его можно открыть без сервера. В браузере PDF сохраняется через окно печати; в Electron — через выбор файла.

В этой облачной среде домашняя папка недоступна для записи. Для установки Electron используются поддерживаемые параметры кеша и прокси Node:

```bash
npm_config_cache=/workspace/.cache/npm npm ci
NODE_USE_ENV_PROXY=1 electron_config_cache=/workspace/.cache/electron npm run desktop:install
```

## Проверки

```bash
npm test
npm run test:browser
```

Модель, DOCX и языковые правила проверяются штатным runner Node. Функциональный сценарий запускает настоящий Electron и собранную браузерную версию: заполнение, форматирование, модули, сохранение и открытие, редактирование шаблонов, копирование и экспорт PDF. В Linux без дисплея тест использует headless Ozone; нужен Chromium для отдельной браузерной проверки (`CHROMIUM_PATH`). Путь кеша в тесте относится к данной облачной среде.

## Сборка файлов для Windows и браузера

```bash
npm run build
python3 scripts/package_setup.py
```

Скрипт создаёт небольшие комплекты в `downloads/`: установочный ZIP для Windows, браузерный ZIP и самостоятельный HTML. Он включает актуальную версию приложения и уведомления о лицензиях. Установщик закрепляет версию Electron и SHA256, не требует администратора и не меняет ExecutionPolicy или настройки защиты.

Для полного переносимого архива с готовым EXE:

```bash
python3 scripts/package_windows.py
```

Этот скрипт получает официальный Windows x64 дистрибутив Electron, сверяет SHA256 с опубликованным `SHASUMS256.txt` и добавляет приложение. Полный ZIP появляется в `release/`; он не хранится в Git из-за размера. Нужны Python 3.10+ и доступ к GitHub releases. Сборка на Linux не означает проверку запуска на Windows. У приложения нет собственной цифровой подписи издателя.

## Устройство

- `src/templates.json` — базовые разделы и модули.
- `src/model.ts` — конструктор документов, проверка и миграция форматов.
- `src/editor.ts` — Tiptap, разделы и редактируемые поля.
- `src/main.ts` — интерфейс, шаблоны и локальное сохранение.
- `src/docx.ts` — экспорт OOXML и восстановление собственных DOCX.
- `src/proofreading.ts` — локальная проверка русского текста.
- `electron/` — оболочка, файловый диалог PDF и буфер обмена.

В Electron отключён Node.js в редакторе, включены sandbox/context isolation, внешние HTTP-запросы и новые окна блокируются. Внешние данные проходят проверку структуры до замены текущего документа. Отключённые модули сохраняются в памяти в пределах текущей сессии.

Альянс предоставляет базовое форматирование текстового редактора. Полная совместимость с произвольными DOCX, колонтитулы Word, отслеживание правок, интеграция с МИС и автоматическая диагностика в эту версию не входят. Медицинский контент не содержит предустановленных находок или фиксированной дозы контраста.
