# МРТ Альянс

Локальный редактор описаний МРТ. Врач выбирает зону и шаблон, заполняет документ, добавляет нужные блоки и сохраняет результат в Word или PDF. Рабочая область — одно поле редактирования без отдельной правой панели.

## Скачать приложение

[Комплект для Windows](https://github.com/002-421/-main/raw/refs/heads/codex/mri-report-studio/mri-report-studio/downloads/MRI_Alliance_Windows_Setup.zip): распакуйте весь архив и запустите `Install.cmd`. Он загрузит официальный Electron с GitHub, проверит SHA256 и создаст новую папку приложения на рабочем столе. Интернет нужен для установки; работа с описаниями выполняется локально.

[Браузерная версия](https://github.com/002-421/-main/raw/refs/heads/codex/mri-report-studio/mri-report-studio/downloads/MRI_Alliance_Browser.zip): распакуйте и откройте `index.html` в Chrome или Edge.

[Подробная инструкция на русском](README_RU.txt). [Пример базового шаблона Word](downloads/MRI_Alliance_Head_Template.docx?raw=true).

## Версия 0.3.0

- **Зона → шаблон** во вкладке «Зоны и шаблоны». Оформление документов опирается на Word-шаблоны, ранее подготовленные для пользователя: порядок разделов, таблицы, заголовки и параметры текста. Возраст и клиническая цель исключены согласно предыдущему запросу.
- **Редактирование на странице.** Нажмите на жёлтую подсказку и начните ввод: текст подсказки заменится вашим текстом. Все данные, находки, заключение и Ф.И.О. врача изменяются в основном документе.
- **Дополнительные описания.** Поиск по библиотеке, просмотр фрагмента и вставка в текущую позицию курсора. Выделенный текст можно сохранить как новый блок вместе с форматированием и использовать в других описаниях.
- **Проверка неизменённых частей.** Кнопка «Подсветить неизменённое» подсвечивает подсказки и стандартные текстовые блоки, которые совпадают с исходным шаблоном. Это напоминание о необходимости проверки, а не автоматическое определение ошибки.
- **Орфография и базовая грамматика в документе.** Красное и синее подчёркивание, подсказки исправления и личный словарь. Проверка работает локально; первая инициализация встроенного русского словаря занимает несколько секунд. Правила не обеспечивают полный синтаксический анализ всех конструкций русского языка.
- **Собственные шаблоны и врачи.** Текст и оформление шаблона редактируются и сохраняются для следующих описаний. В «Врач и настройки» можно изменить имя по умолчанию и при необходимости применить его к текущему описанию.
- **Word и PDF.** «Сохранить Word» сохраняет настоящий OOXML-документ с форматированием и таблицами. PDF содержит сам отчёт, без интерфейса, рабочих подчёркиваний и подсветки проверки неизменённых частей.

Незаполненная подсказка остаётся текстом документа до заполнения или удаления. Подсветка не заменяет вычитку: изменение одного слова в абзаце не подтверждает правильность остальных слов.

DOCX, выгруженный из приложения, можно повторно открыть с восстановлением данных редактирования, пока файл не изменён другим редактором. Изменённые в Word и произвольные сторонние DOCX не импортируются; нужный текст можно скопировать в редактор. Старые `.mri.json` читаются для совместимости.

Один рабочий черновик, настройки шаблонов, дополнительные блоки, имя врача и пользовательский словарь хранятся локально. Для архива исследований сохраняйте каждое описание отдельным DOCX или PDF. Приложение не выполняет медицинскую диагностику и не связано с исследовательским разбором снимков в чате.

## Запуск из исходников

Требуется Node.js 24 LTS. Версии зависимостей зафиксированы в `package-lock.json`.

```bash
npm ci
npm run build
npm run desktop:install
npm start
```

Разработка в браузере: `npm run dev`. Собранный `dist/index.html` самодостаточен: код, стили, каталог шаблонов и словарь включены в файл. В браузере PDF сохраняется через окно печати; в Electron — через файловый диалог.

Для данной облачной среды с ограниченной домашней папкой:

```bash
npm_config_cache=/workspace/.cache/npm npm ci
NODE_USE_ENV_PROXY=1 electron_config_cache=/workspace/.cache/electron npm run desktop:install
```

## Проверки

```bash
npm test
npm run test:browser
```

Unit-тесты проверяют модель, каталог шаблонов, структуру DOCX, поля и языковые правила. Функциональный сценарий использует настоящий Electron и собранный браузерный файл. В Linux без дисплея применяется headless Ozone; отдельной браузерной проверке нужен Chromium (`CHROMIUM_PATH`). Можно указать путь к Electron через `ELECTRON_PATH`.

## Сборка комплектов

```bash
npm run build
python3 scripts/package_setup.py
```

В `downloads/` создаются установочный ZIP, браузерный ZIP, самостоятельный HTML и лицензии. Прежние имена `MRI_Report_Studio_*` сохранены как совместимые копии актуальных комплектов, чтобы старые ссылки продолжали работать. Установщик закрепляет версию Electron и SHA256; права администратора, изменение ExecutionPolicy и настроек защиты не требуются.

Полный переносимый архив с Windows EXE:

```bash
python3 scripts/package_windows.py
```

Скрипт сверяет официальный Electron x64 с опубликованным `SHASUMS256.txt`. Полный ZIP находится в `release/` и не хранится в Git из-за размера. Требуются Python 3.10+ и доступ к GitHub releases. Сборка на Linux не подтверждает запуск на Windows; у приложения нет собственной цифровой подписи издателя.

## Устройство

- `src/catalog.ts`, `src/catalog.json` — зоны и шаблоны, подготовленные из наших Word-примеров.
- `src/model.ts` — общая модель и совместимость с прежними черновиками.
- `src/editor.ts`, `src/inline-fields.ts` — основной редактор и поля с заменяемыми подсказками.
- `src/live-proofreading.ts` — подчёркивания и сопоставление замечаний позициям редактора.
- `src/proofreading.ts`, `src/proofreading-core.ts` — локальный словарь и правила.
- `src/main.ts` — интерфейс, библиотека блоков, шаблоны и локальное сохранение.
- `src/docx.ts` — экспорт OOXML и восстановление собственных DOCX.
- `electron/` — оболочка, PDF и буфер обмена.

В редакторе Electron отключён Node.js, включены sandbox/context isolation. Внешние HTTP-запросы и новые окна блокируются; текст не отправляется на сервер. При импорте файлы проверяются до замены текущего документа.

DejaVu Sans и Carlito встроены в браузерный bundle; Carlito используется как метрически совместимая замена Calibri при отображении исходных заголовков. В DOCX встраиваются четыре начертания DejaVu Sans, а заголовки сохраняют исходный Calibri. Отдельная установка этих шрифтов для приложения не требуется; поведение сторонних редакторов с вложенными шрифтами может отличаться. Полная совместимость с произвольными DOCX, отслеживание правок Word и интеграция с МИС в эту версию не входят.

Официальный логотип МРТ Альянс встроен в верхнюю часть приложения и значок Windows; в «Врач и настройки» его можно заменить другим файлом PNG/JPEG/WebP до 2 МБ. Логотип интерфейса не меняет макет исходных Word-шаблонов.
