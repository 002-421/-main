# Пользовательские материалы

Загружайте сюда логотип МРТ Альянс (предпочтительно `logo.png`) и дополнительные исходные шаблоны Word.

В GitHub откройте эту папку, выберите **Add file → Upload files**, добавьте файлы и сохраните изменения в ветке `codex/mri-report-studio`.

Папка предназначена для исходных материалов. Готовые файлы приложения и шаблон отчёта находятся в `downloads/`.
