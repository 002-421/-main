МРТ · Студия описаний — версия 0.1.0

Windows 10/11, 64 бит
1. Распакуйте архив целиком в любую доступную папку, например «Документы\МРТ Студия».
2. Откройте папку «MRI Report Studio» и запустите «MRI Report Studio.exe».
3. Приложение работает локально и не требует Python, Node.js, Word или Интернета.
Приложение не имеет цифровой подписи издателя; установка в систему не производится.

Работа с описанием
Слева выберите дополнительные модули. Жёлтые поля заполняются через правую панель: нажмите на поле, введите текст, затем «Далее» или Ctrl+Enter. Любой обычный текст можно редактировать прямо в документе. Необязательное поле можно удалить. Подсветку заполненных полей можно отключить кнопкой на панели; при выгрузке PDF она снимается автоматически. Незаполненные поля остаются видимыми.

Форматирование
Доступны шрифты и размер, полужирный, курсив, подчёркивание, зачёркивание, цвет и выделение, выравнивание, списки, межстрочный интервал, вставка и редактирование таблиц, отмена и повтор. Это самостоятельный редактор с базовым форматированием, а не полная замена Microsoft Word.
«Копировать» переносит текст с форматированием в Word через буфер обмена.

Модули и области
«Новое» позволяет выбрать головной мозг, МРА, МРВ, гипофиз, орбиты, пазухи или другую область. Существующее описание при этом заменяется: нужный вариант сохраните файлом заранее.
В библиотеке 12 специализированных модулей на основе ваших шаблонов и отдельный повторяемый блок находки. При отключении модуля его правки временно сохраняются до закрытия приложения; повторное включение в той же сессии восстанавливает их. Для долгого хранения оставляйте нужный модуль включённым и сохраняйте файл описания.
Библиотека → Новый модуль: введите название и текст; переменные поля обозначайте [[двойными квадратными скобками]]. Свои модули можно сохранить и перенести файлом библиотеки JSON. Импорт не заменяет уже существующие ID.

Сохранение
Текущий черновик автоматически сохраняется в профиле приложения на этом компьютере. Это один рабочий черновик, не архив пациентов. «Сохранить» выгружает отдельный файл .mri.json с текстом, форматированием, полями и своими модулями. «Открыть» восстанавливает его. Для хранения нескольких описаний сохраняйте каждое отдельным файлом.
«PDF» открывает диалог выбора папки и сохраняет итоговый документ A4. PDF содержит выделяемый текст и кириллицу; интерфейс приложения в него не попадает. При незаполненных полях приложение предлагает вернуться к ним или выгрузить текущий вариант.

Локальная работа
Данные не отправляются на сервер. Приложение не подключено к медицинской информационной системе. Готовое заключение формирует и проверяет врач; диагнозы и нормальные находки автоматически не назначаются.

Дополнительная версия
MRI_Report_Studio.html — автономная версия для браузера. Откройте её двойным щелчком в Chrome или Edge. Для PDF выберите «Сохранить как PDF» в окне печати. Сохранение черновика в браузере привязано к этому браузеру и расположению файла; используйте файлы .mri.json для переноса и резервных копий.

Данные и удаление
Файлы .mri.json и PDF содержат внесённые вами данные пациента. Выбирайте подходящую папку для их хранения. Для полного удаления локального черновика закройте приложение и удалите папку профиля «MRI Report Studio» в %APPDATA%, если она создана в вашей системе. Выгруженные файлы удаляются отдельно.
