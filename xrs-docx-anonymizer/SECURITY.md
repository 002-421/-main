# Защита данных

- В приложении нет HTTP-клиента, сетевых вызовов, облачных API, телеметрии, отправки логов и автоматического обновления.
- UNC-пути и подключённые сетевые диски Windows отклоняются до обхода папок. Не выбирайте каталоги облачной синхронизации: их фоновая работа управляется ОС, а не утилитой.
- Оригиналы только читаются. Исходный пакет не сохраняется во временные файлы и не включается в выходной ZIP.
- В памяти находятся исходный документ и промежуточное дерево. Защита памяти, файла подкачки, аварийных дампов и резервных копий — задача локального контура Windows.
- Отчёты содержат только CASE-ID, статус, счётчики и фиксированные коды. Нет имён файлов, путей, найденных значений и текстов исключений.
- Нет таблицы соответствия исходных имён и CASE-ID. Пустые файлы `.reservations` содержат только безопасный код.
- REVIEW_REQUIRED может содержать персональные данные: это изоляция по папкам, не шифрование и не ACL. До запуска ограничьте доступ к источнику, Review и результатам средствами Windows. Для медицинских данных используйте локальный разрешённый диск с BitLocker; не выбирайте папку облачной синхронизации.

## Ограничения ресурсов

| Ограничение | Значение |
| --- | --- |
| Размер исходного DOCX | 128 МиБ |
| Количество ZIP-записей | 2048 |
| Размер отдельной распакованной части | 16 МиБ |
| Суммарный распакованный размер | 64 МиБ |
| Отношение распакованного размера к сжатому | 250 |
| XML-узлы в одной части | 250 000 |

Также запрещены ZIP-пути с выходом из корня, абсолютные пути, обратные слеши, дубликаты, ZIP-симлинки, шифрование, DTD и сущности. Используются защитные лимиты глубины lxml. Большой, но безопасный документ тоже может получить FAILED; это намеренное ограничение MVP.

Приложение не является антивирусом и не создаёт песочницу ОС. Для недоверенных архивов рекомендуется отдельная учётная запись или изолированная рабочая станция без сети. Нет гарантии защиты от неизвестной уязвимости Python/lxml/libxml2 или исчерпания памяти при предельных входных данных. Отмена не прерывает текущий разбор XML.

## Проверки отсутствия сети

Автоматические тесты запрещают socket.connect, create_connection и DNS getaddrinfo на время полного синтетического запуска; вызовов нет. XML использует no_network и не разрешает сущности. Это проверка кода в Linux, а не инструментальное наблюдение Windows EXE. Перед допуском дистрибутива отдельно проверьте EXE в Windows Firewall / Process Monitor с отключённой сетью. Не отключайте защиту Windows ради этой проверки.

## GitHub и сборка

Сборка допускает только код, зависимости и синтетические тесты. Никогда не добавляйте реальные DOCX, Review, Anonymized, Reports и диагностические дампы в Git. `.gitignore` содержит дополнительные исключения, но не заменяет ручную проверку staged files. GitHub Actions не получает медицинских файлов. Portable-сборка включает Python и lxml; их обновления требуют новой проверенной сборки.
