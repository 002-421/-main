# Подтверждённые результаты испытаний

Дата: 18.11.2026 (Asia/Novosibirsk). Использовались только синтетические документы.

## Linux / исходный код

- Python 3.12.14, lxml 6.1.1, python-docx 1.2.0, Pillow 13.0.0.
- `python -m compileall -q xrs_anonymizer tests tools`: OK.
- `python -m unittest discover -s tests -t . -q`: **63 теста, OK, 11,677 с**.
- Включён пакет из **1000 DOCX** и повторная обработка в ту же папку без перезаписи первого результата.
- Проверены Ф.И.О. врача и пациента, заглавные имена, инициалы, подписи, даты рождения/исследования, номера, email/телефоны/адреса/идентификаторы и сведения в таблицах.
- Проверены реальные PNG/JPEG в тексте, таблице, header/footer; также удаление медиа с расширениями TIFF/BMP/GIF/EMF/WMF/SVG, orphan media, OLE, внешних связей, свойств и customXml.
- Проверены комментарии, удаления/вставки/moveFrom в Track Changes, поля, скрытый текст, наследуемые стили скрытия, явное выключение скрытия и скрытие в docDefaults.
- Проверены сноски, текстовые блоки VML, границы runs/переносов строк, стиль и нумерация, повторное открытие результатов через python-docx.
- Измерения `12 × 8 × 4,5 мм`, `ADC 0,9 × 10⁻³ мм²/с`, `L4-L5`, `T1/T2`, стороны и медицинские эпонимы сохраняются в соответствующих тестах.
- Проверены повреждение ZIP/XML, ZIP bomb, path traversal, дубликаты, лимит записей, DTD/XXE в UTF-8 и UTF-16, неизвестный контейнер, неверная вложенность, небезопасная ссылка на header и остаточный идентификатор во втором проходе.
- Проверены изоляция REVIEW_REQUIRED, отсутствие DOCX для FAILED, блокировка параллельного запуска, отмена, отсутствие исходных значений/путей в отчётах и неизменность оригинала.
- Проверены все календарные даты в числовых, ISO, текстовых русских и разделённых между runs формах: исходное значение заменяется словом «дата», включая дату сравнения и дату рождения. Некорректный или неоднозначный кандидат нейтрализуется и переводится в REVIEW_REQUIRED; измерения, диапазоны, уровни, последовательности и классификации остаются без изменений.
- Проверено полное удаление header/footer XML-parts, их relationships, ссылок секций, таблиц и встроенных графических объектов для нескольких секций и first/even/default вариантов.
- Проверены дословное сохранение строки «Область и вид исследования» с независимой проверкой, удаление отдельного служебного абзаца об аппарате при сохранении его упоминания в клиническом сравнении и пять синтетических структур протоколов МРТ/КТ.
- Проверена дословная сохранность поля вида исследования как в отдельной строке, так и в таблице с меткой и значением в соседних ячейках.
- Проверена крупная структура: 1800 синтетических абзацев и таблица на 120 строк без потери содержимого.
- Полный синтетический запуск под запретом socket.connect/create_connection/getaddrinfo прошёл без сетевых/DNS вызовов.
- Подтверждено наличие бинарных Windows x64 wheels для закреплённых основных зависимостей.

## GUI

Окно проверено на Linux с системным Python/Tk 8.6. Выполнен запуск из GUI на четырёх синтетических DOCX: ожидаемые 2 PASS, 1 REVIEW_REQUIRED и 1 FAILED; интерфейс показал завершение, папки и отчёты проверены отдельно. Встроенная в среду разработки сборка Python с Tk 9.0 некорректно отображает кириллицу; системный Tk 8.6 отображает интерфейс правильно. Windows-сборка использует официальный Python 3.12 и Tk 8.6. Linux-проверка не заменяет проверку Windows GUI.

## Windows

Для актуальной сборки откройте [Windows CI для ветки](https://github.com/002-421/-main/actions/workflows/xrs-docx-anonymizer-windows.yml?query=branch%3Acodex%2Fxrs-docx-anonymizer) и выберите последний успешный запуск. Workflow выполняет тесты, собирает GUI и CLI, проверяет frozen CLI и создаёт Windows x64 artifact. Предыдущие артефакты статусов до `REVIEW_REQUIRED` / `FAILED` не относятся к текущему статусному контракту. `BUILD_EVIDENCE.json` фиксирует платформу, SHA коммита и число тестов конкретной сборки. Artifacts хранятся 14 дней; исходники и workflow остаются в отдельной ветке.

Windows 11 x64 / Microsoft Word и инструментальное наблюдение сетевой активности frozen EXE требуют приёмочной проверки. Открытие через python-docx не является подтверждением отрисовки Word или полной XSD-валидацией.
