# XRS-09 — домашняя проверка Stable 0.4.55

Пакет собирается существующими `scripts/package_setup.py` и `scripts/install_windows.ps1` в режиме кандидата. Он использует обычную Stable-установку, не использует Beta launcher и не меняет `downloads/latest.json`.

## Установка на домашнем компьютере

1. Скачайте ZIP и SHA-256 из одного проверенного Windows CI Artifact. Сверьте:

   ```powershell
   Get-FileHash .\X-ray_Report_Studio_Windows_Setup.zip -Algorithm SHA256
   ```

2. Распакуйте весь ZIP и закройте X-ray Report Studio 0.4.54.
3. Запустите `Install.cmd`. Для тестового пакета установщик проверит ярлык и версию 0.4.54, проверит закрытие приложения и отсутствие Beta-профиля.
4. Прочитайте предупреждение и введите `UPDATE 0.4.54 TO 0.4.55`.
5. Дождитесь загрузки официального Electron runtime, проверки его SHA-256 и открытия редактора.
6. Проверьте существующие вкладки/черновики, пользовательские шаблоны и словарь, затем DOCX/PDF, Undo/Redo и повторный запуск.

Новая папка приложения создаётся рядом с прежней; прежняя 0.4.54 не удаляется. Stable-профиль `%APPDATA%\MRI Report Studio` установщик не перемещает и не очищает. Ярлык меняется только для текущего Windows-пользователя; другие компьютеры и общий канал обновлений не затрагиваются.

## Возврат к 0.4.54

Установщик сохраняет предыдущий ярлык как `.XRS-previous-*.lnk` на рабочем столе и сохраняет папку 0.4.54 в `Рабочий стол\X-ray Report Studio`. Закройте приложение, переименуйте текущий `X-ray Report Studio.lnk` в `X-ray Report Studio 0.4.55.lnk`, а сохранённый `.XRS-previous-*.lnk` — в `X-ray Report Studio.lnk`. Не удаляйте ни одну папку версии. Профиль остаётся текущим; не восстанавливайте старую копию поверх него.

Windows CI использует `windows-2022`, не домашний Windows 11. CI проверит Electron integration, синтетическое side-by-side обновление, DOCX/PDF, Undo/Redo, workspace recovery и пакет. Фактическое обновление установленного домашнего профиля остаётся ручным тестом.
