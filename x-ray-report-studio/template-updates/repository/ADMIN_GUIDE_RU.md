# Как обновить медицинский шаблон для всех врачей XRS

**Состояние: инструкция к разрабатываемой системе. Производственная публикация
пока заблокирована; сейчас можно подготовить и проверить локальное предложение.**

1. Возьмите каталог из официального репозитория `002-421/XRS-Templates`.
   Установите Node.js 24 один раз. Выполните первоначальную установку зависимостей
   по README; затем запускайте `Start-Template-Admin.cmd` и откройте показанный адрес.
2. Выберите нужный шаблон. Это библиотека, а не открытый протокол пациента.
   Редактор показывает исходную версию и автоматически предлагает следующую.
3. Исправьте медицинский текст. Сохранённое оформление и специальные поля
   защищены. Сверьте сравнение «БЫЛО / СТАЛО» и список полей/размеров.
4. Жёлтый абзац и каждый размер — разные системные объекты. Не заменяйте их
   обычной цветной заливкой; не удаляйте служебные ID. В текущем инструменте
   изменение набора полей и добавление новых размеров недоступны.
5. Если вы редактировали DOCX в Word, примите или отклоните все исправления.
   Полный перенос такого файла в новый инструмент ещё не реализован. Не обходите
   предупреждение копированием в JSON: передайте файл ответственному редактору,
   пока штатный двусторонний обмен не будет завершён и проверен в реальном Word.
6. При создании нового шаблона используйте раздел «Новый шаблон или группа»:
   задайте название и при необходимости новую группу. Постоянный ID создаётся
   автоматически; исходный шаблон не заменяется. Получите медицинское утверждение, укажите его номер/ссылку и краткое описание
   изменений, подтвердите отсутствие персональных данных. Скачайте `.xrsproposal`.
   Он ещё не подписан и не устанавливается на компьютерах врачей.
7. После завершения настройки системы уполномоченный администратор загрузит
   предложения в `incoming/` через GitHub (для нескольких изменений укажите
   имена файлов через запятую в одном запуске), дождётся проверки и утверждения PR,
   запустит `Publish approved template catalog` и подтвердит защищённое развёртывание.
   Обычному врачу права публикации и GitHub-токен не нужны.
8. Проверьте успешный workflow и наличие подписанного манифеста/пакетов в GitHub
   Release. Страница тега и тестовый Artifact не заменяют опубликованный каталог.
9. После выпуска поддерживающей эту функцию версии XRS врач откроет
   «Врач и настройки → Медицинские шаблоны», нажмёт «Обновить шаблоны», проверит
   список изменений и нажмёт «Установить». Открытые протоколы сохранятся;
   новую редакцию используют только новые документы.
10. При необходимости нажмите «Вернуть предыдущую версию шаблонов» и подтвердите
    откат. Ранее созданные протоколы при этом не переписываются. Отдельный откат
    одного шаблона пока не реализован.

До завершения защищённой публикации, Windows-проверок и теста двух экземпляров
не считайте распространение шаблонов для всех врачей готовым. Публикация
синтетического теста разрешена только в изолированном тестовом канале.
