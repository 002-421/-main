XRS — локальная резервная копия перед обновлением

Утилита XRS-PreUpdate-Backup.ps1 создаёт отдельную проверенную копию данных перед переходом с 0.4.53 на 0.4.54. Она ничего не восстанавливает, не меняет профиль приложения и не удаляет старые копии.

Что копируется
- Все файлы профиля %APPDATA%\MRI Report Studio, включая открытые протоколы, настройки, шаблоны, подписи, печати, личный словарь и данные Chromium.
- Общий словарь из фактического каталога MRI_REPORT_STUDIO_DICTIONARY_DIR\dictionary.json, если переменная задана и файл существует.
- Стандартный общий словарь %PUBLIC%\Documents\MRI Report Studio\dictionary.json, если он существует.
- Если приложение использует личный dictionary.json в профиле, он уже включён в полную копию профиля.

Перед запуском
1. Закройте X-ray Report Studio и дождитесь закрытия всех его окон.
2. Выберите доступный локальный диск с достаточным местом, например отдельную папку на D: или USB-диске. Не выбирайте папку профиля приложения, папку Desktop\X-ray Report Studio или каталог App_* установленной версии. Сетевые диски не поддерживаются.
3. Не закрывайте окно PowerShell до появления результата BACKUP VERIFIED.

Запуск в Windows 11
1. Скопируйте оба файла XRS-PreUpdate-Backup.ps1 и XRS-PreUpdate-Backup-README_RU.txt в доступное место.
2. Откройте меню «Пуск», найдите Windows PowerShell и выберите «Запуск от имени пользователя» (права администратора не нужны).
3. Выполните команду, заменив путь на выбранный каталог резервных копий:

   powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\путь\XRS-PreUpdate-Backup.ps1" -DestinationRoot "D:\XRS-резервные-копии"

   Если приложение использует нестандартный общий словарь, передайте его полный путь параметром -DictionaryPath. Если профиль приложения расположен нестандартно, используйте -ProfilePath.
4. Убедитесь, что показано BACKUP VERIFIED. Сохраните выведенный путь к папке копии. При BACKUP FAILED обновление пока не выполняйте; освободите место, закройте приложение либо устраните проблему доступа и повторите резервирование.

Проверка и восстановление вручную
Манифест manifest.json содержит относительный путь каждой копии, размер и SHA-256. Не редактируйте его. Для проверки целостности можно открыть PowerShell и выполнить команды ниже, заменив $backup на путь, показанный после BACKUP VERIFIED:

   $backup = 'D:\XRS-резервные-копии\XRS_PreUpdate_0.4.53_to_0.4.54_...'
   $manifest = Get-Content -LiteralPath (Join-Path $backup 'manifest.json') -Raw -Encoding UTF8 | ConvertFrom-Json
   foreach ($file in $manifest.files) {
       $path = Join-Path (Join-Path $backup 'data') ($file.backupPath -replace '/', '\')
       $item = Get-Item -LiteralPath $path
       $hash = (Get-FileHash -LiteralPath $path -Algorithm SHA256).Hash.ToLowerInvariant()
       if ($item.Length -ne [long]$file.bytes -or $hash -ne $file.sha256) { throw 'Проверка не пройдена. Не используйте эту копию.' }
   }
   'MANIFEST CONTENTS VERIFIED'

Утилита не выполняет автоматический откат. Если понадобится ручное восстановление:
1. Закройте приложение и убедитесь, что оно не запущено.
2. Сначала переименуйте текущую папку %APPDATA%\MRI Report Studio в отдельную папку, например MRI Report Studio до восстановления. Не удаляйте её.
3. Скопируйте содержимое папки <копия>\data\profile обратно в %APPDATA%\MRI Report Studio. Команда robocopy сохраняет вложенные и скрытые файлы:

   robocopy "D:\...\data\profile" "%APPDATA%\MRI Report Studio" /E /COPY:DAT /DCOPY:DAT /R:1 /W:1 /XJ

   Коды robocopy от 0 до 7 означают, что копирование завершилось без критической ошибки; код 8 или выше означает ошибку.
4. Для внешнего общего словаря найдите запись с source="external-dictionary" в манифесте. Сначала сохраните текущий dictionary.json отдельно, затем вручную скопируйте соответствующий файл из data\dictionaries в записанный sourcePath. Личный словарь внутри профиля уже восстановлен вместе с профилем.
5. Запустите приложение и проверьте документы и настройки. Сохраните исходную и текущую папки до подтверждения успешного восстановления.

Утилита отказывает при работающем приложении/Electron, нехватке места, проблемах доступа, ссылках/reparse points, изменении источников во время копирования или ошибке проверки. Предыдущие резервные копии никогда не перезаписываются. В консоль не выводятся тексты документов или содержимое файлов.
