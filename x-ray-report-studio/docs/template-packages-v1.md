# XRS 0.4.71 — DOCX для проверки шаблонов

Основа: xrs-v0.4.70, `38ff90a2fe4e7614de848f271eb3260216d608e6`.

В меню «Шаблоны Word для медицинской проверки» выберите зону, группу и отдельные шаблоны. Один шаблон экспортируется DOCX; группа экспортируется ZIP с отдельным DOCX для каждого шаблона и manifest.json. Экспорт не читает открытые протоколы, настройки врача, словарь, печати или подписи. Перед внешней передачей проверьте собственные правки шаблонов на персональные данные.

DOCX содержит структурированные Tiptap данные XRS, служебный templateId, исходный SHA-256 и версию приложения. В `word/settings.xml` включён `w:trackRevisions`, добавлена часть comments для комментариев рецензента. Вставки/удаления, создаваемые врачом в Microsoft Word, отображаются стандартными средствами Word и могут приниматься/отклоняться по отдельности. Экспорт не генерирует медицинские предложения сам.

Перед импортом разрешите все исправления в Word и сохраните DOCX. XRS отклоняет документ, если в OOXML остались `w:ins`/`w:del` в документе или связанных частях Word. Каждый файл импортируется отдельно. Сопоставляются ID, исходный SHA и контракт. Конфликт исходной версии блокирует применение. Предпросмотр показывает БЫЛО/СТАЛО; применение требует явного подтверждения. Создаётся автоматическая проверенная резервная копия; откат затрагивает только импортированный шаблон. Открытые документы, настройки и словарь не изменяются.

Группа ZIP содержит один DOCX на шаблон и `manifest.json`; для импорта распакуйте архив и загрузите утверждённые DOCX по одному. JSON не является пользовательским форматом и вручную редактировать его или вычислять хеш не требуется.

Тесты проверяют структуру OOXML, `w:trackRevisions`, комментарии, baseline конфликт, вставку/удаление pending revisions, импорт разрешённого изменения, резервирование и откат. Реальный Microsoft Word в этой среде не запускался; совместимость с Word по фактическому открытию и Track Changes требует ручной проверки на Windows 11.

Ручная приёмка: экспортировать 15 МРТ шаблонов головы; открыть DOCX в Word; вставить и удалить текст с Track Changes; частично принять/отклонить, сохранить и убедиться, что оставшиеся исправления блокируют импорт; разрешить все изменения, импортировать выбранные файлы, проверить форматирование, перезапуск шаблона и откат.
