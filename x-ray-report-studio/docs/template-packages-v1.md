# XRS 0.4.71 — пакеты шаблонов v1

Основа: xrs-v0.4.70, 38ff90a2fe4e7614de848f271eb3260216d608e6.

В боковом меню «Пакеты шаблонов»: зона → МРТ/КТ → отдельные шаблоны или вся группа. Экспорт читает библиотеку и её пользовательские переопределения, не читает открытые документы, словарь, настройки или изображения врача. Собственные правки библиотеки перед внешней передачей следует проверить на персональные данные.

ZIP содержит manifest.json, templates/<id>.json, readable/<id>.txt и README.txt. schemaVersion=1; xrsVersion; для каждой записи id/title/areaId/group/file/baseSha256/sha256. SHA-256 считается над JSON с рекурсивно отсортированными ключами; порядок массивов сохраняется. После медицинской правки измените JSON и sha256, сохраняя baseSha256. TXT — справочный текст, его изменения не импортируются. DOCX не считается обратимым форматом пакета; существующий одиночный импорт Word доступен отдельно.

JSON сохраняет поддерживаемые Tiptap узлы, метки, поля, разделы и templateId; пустые узлы и значения по умолчанию нормализуются валидатором XRS. Неподдерживаемое форматирование, неизвестный ID, несовместимая схема, неверная сумма и конфликт исходного хеша блокируются. Новые ID не создаются этой версией.

Выбор ZIP только проверяет пакет. Для каждой изменённой записи раскрыть БЫЛО/СТАЛО, проверить оформление и выделенные строки JSON, выбрать решение. По умолчанию «Не подтверждено». Кнопка применения сохраняет только явно принятые изменения. SHA — проверка целостности, не подпись и не медицинское одобрение.

Переопределения сохраняются в прежнем ключе mri-alliance.templates.v4. Пакетный импорт хранит проверенную исходную копию, журнал незавершённой операции и отчёт в xrs.template-package-*.v1. При ошибке записи и после прерывания восстанавливается исходная запись. Откат последнего пакета восстанавливает только затронутые ID; другие шаблоны и рабочие документы не затрагиваются. Резервная копия последнего пакета локальная: очистка профиля удалит её. Подтверждённые шаблоны используются только при создании новых документов.

Ручная приёмка: обе темы → PDF одной/нескольких страниц; проверить фон, выделяемый текст, поля, подпись. Настройки врача → высота и смещения −100/−85/0/85/100 → сохранить → перезапуск → DOCX/PDF. Экспорт МРТ головы → неизменённый импорт → одно адресное изменение → предпросмотр → принятие → новый документ → откат. Проверить два открытых отчёта и Undo/Redo; они не должны измениться при импорте.

Updater и release workflow не изменены. Контракт данных сохранён; 0.4.71 добавлена в allowlist версий. Реальный переход 0.4.70 → 0.4.71 требует пользовательской проверки после отдельного разрешения публикации.
