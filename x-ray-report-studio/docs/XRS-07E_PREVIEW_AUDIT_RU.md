# XRS-07E — аудит предпросмотра DOCX

## Причины расхождения

До исправления браузерный предпросмотр принудительно отображал основной текст как 10 pt, тогда как экспорт DOCX использовал 12 pt. Алгоритм считал высоту каждого блока без межабзацных отступов, применял фиксированный предел 850 px и переносил длинный абзац целиком. Страница предпросмотра имела нижнее поле 24 мм, экспорт DOCX — около 16 мм. Эти различия могли показать две страницы там, где текст Word переходил на третью.

В DOCX межстрочный интервал `w:lineRule="auto"` умножает естественную высоту строки шрифта. CSS `line-height:1.05` умножает размер шрифта, поэтому исходная строка в браузере оказывалась короче. Для встроенного Arial предпросмотр теперь учитывает поправку к высоте строки. Это приближение, а не гарантия совпадения с конкретной установкой Word.

## Архитектура

Выбрана синхронизация лёгкого браузерного предпросмотра с параметрами DOCX. Размер страницы, поля, основной шрифт и область текста берутся из модели, используемой для экспорта. Высота блоков измеряется в браузере с учётом всех отступов. Длинные абзацы разбиваются на продолжения страниц; явный разрыв страницы и `keepNext` учитываются. Колонтитул показывается на каждой странице. Блок, который не удалось вместить, отмечается оранжевой рамкой.

Рендеринг самого DOCX в приложении потребовал бы дополнительного движка и всё равно не воспроизвёл бы гарантированно Microsoft Word. Обновлённый предпросмотр явно предупреждает о возможном различии переносов и необходимости проверить сохранённый DOCX перед отправкой.

## Синтетическое сравнение

На Linux выполнено независимое преобразование DOCX через LibreOffice. Количество страниц совпало с браузерным предпросмотром для документов с 10, 38, 55 и 65 абзацами: соответственно 1, 2, 3 и 4 страницы. Сценарии с длинным абзацем, таблицей, разными размерами текста, явным переносом и заключением проверяются отдельно в браузерном тесте на выход за границы страницы. Microsoft Word в среде тестирования не установлен; фактическая точность разбиения в нём требует ручной проверки на Windows 11.

Тестовые документы содержат только искусственный текст. Медицинские формулировки, шаблоны и данные пациентов не менялись.
