Base: xrs-v0.4.86 = b139808e0e28e00fe69c4ca421c1c69062671427.

Every ordinary paste ignores source styling and fields, including internal XRS markers. Plain clipboard text is used when available, otherwise the parsed ProseMirror slice supplies text. Existing destination field handlers retain placeholder behavior. Nonempty target: use insertion marks and its paragraph attrs. Empty target: inherit immediately preceding sibling text block and its last non-whitespace text run. No previous sibling: use current paragraph/document defaults. New paragraphs receive the target attributes; unchanged neighboring blocks remain intact.

Indent menu: 0, 0.5, 0.625, 0.75, 1 and 1.25 cm. Only explicit selection applies cm * 72 / 2.54. Existing attrs (including 1.5 cm and larger) are preserved exactly. Source values are paragraph.attrs.firstLineIndentPt in src/catalog.json and src/ct-catalog.json, rendered by SourceFormat in src/inline-fields.ts as text-indent in pt. DOCX export in src/docx.ts rounds to integer twips; import divides by 20.

Existing PIN, approved-only publisher, conflict/version checks, immutable Releases and catalog store are reused.
