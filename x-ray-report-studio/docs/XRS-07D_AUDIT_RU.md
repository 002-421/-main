# XRS-07D — аудит альтернатив в шаблонах МРТ и КТ

Автоматический аудит встроенной библиотеки. Решение о медицински спорных формулировках принимает врач. Текст, порядок абзацев и ID полей не менялись.

Проверено шаблонов: **113** (МРТ: **55**, КТ: **58**). Подтверждено групп выбора: **47** в **11** шаблонах; полностью выделено жёлтым **137** абзацев. Остальные существующие поля выбора и измерения сохраняют прежнюю подсветку.
