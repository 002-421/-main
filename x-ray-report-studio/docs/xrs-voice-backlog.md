# XRS Voice — будущая задача, реализация не начата

Исследовать распознавание русской медицинской речи; Web Speech API в Google
Chrome и фактическую доступность on-device recognition для `ru-RU`.
Сравнить с офлайн-движками. Не отправлять клиническую диктовку на внешние
серверы; возможность локальной обработки должна быть доказана, а не
предполагаться из названия API.

Отдельный последующий этап — преобразование диктовки в структурированный
протокол с обязательным подтверждением результатов врачом.

В текущем задании нет микрофонных разрешений, зависимостей, сетевых вызовов,
модуля распознавания или перевода XRS на веб-архитектуру.
