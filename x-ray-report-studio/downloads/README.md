# X-ray Report Studio

Прямые ссылки на установщик и автономную браузерную версию публикуются в основном [README](../README.md). Установщик создает папку **X-ray Report Studio** и ярлык с этим названием.

Обновление показывает прогресс загрузки и пишет технический журнал в профиль приложения, в папку `logs`. В настройках есть кнопка «Открыть журнал обновлений». Журнал содержит этапы установки и ошибки, но не тексты описаний и не данные пациентов.
